# Project Sofia

**SOAR + LLM CASCADE** — автономный ИИ-ассистент с когнитивной архитектурой.

Архитектура: SOAR (цели, импассы, чанкинг) + каскад LLM (экстрактор → мозг → критик) + CLIPS (безопасность, память). Полностью локальное исполнение.

## Железо
- RTX 5050 8 ГБ / 16 ГБ RAM
- Ollama: qwen3:4b (мозг), qwen3:1.7b (экстрактор), bge-m3 (эмбеддинги)

## Быстрый старт
```bash
ollama pull qwen3:4b qwen3:1.7b bge-m3
pip install -r requirements.txt
uvicorn main:app --reload
```

## Структура
- `core/` — когнитивный цикл, эмоции, навыки
- `memory/` — эпизодическая память + библиотека (папка с книгами)
- `modules/` — TTS, аватар, Telegram
- `config/` — настройки

## Голос
Для клонирования голоса положите 5–8 WAV-файлов (10–30 сек, 22+ кГц, моно, тихая комната) в `data/voice_samples/`. Не коммитьте их в git.
