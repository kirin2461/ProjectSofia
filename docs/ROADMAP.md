# Roadmap: Project Sofia

## Философия
Каждая фаза — законченный инкремент. Не начинаем Phase N+1, пока Phase N не прошла тестирование.

## Архитектура (кратко)
SOAR (цели, чанкинг) + LLM Cascade (экстрактор 1.7b → мозг 4b → критик 4b) + CLIPS (безопасность) + Chroma (память).

---

## Phase 0: Инфраструктура (2–3 дня)
**Цель:** железо готово, модели скачаны, API отвечает.

- [ ] Проверка Ollama и всех моделей (`scripts/check_ollama.py`)
- [ ] Настройка `.gitignore`, структура папок `data/`
- [ ] Тест скорости: 4b > 40 ток/с, 1.7b > 100 ток/с
- [ ] Настройка 780M в BIOS (512 МБ shared memory)
- [ ] `settings_local.py` с переопределениями

**Блокер:** нет.

---

## Phase 1: Голос (XTTS) (3–5 дней)
**Цель:** ассистент говорит вашим голосом (или выбранным).

- [ ] Запись 5–8 референсных WAV (инструкция в README)
- [ ] Установка Coqui TTS, загрузка XTTS v2
- [ ] `modules/tts_engine.py` — клонирование и генерация
- [ ] Интеграция в WebSocket: текст → аудио → браузер
- [ ] Тест русского языка и интонаций

**Блокер:** Phase 0.

---

## Phase 2: Разговорный модуль (5–7 дней)
**Цель:** живой диалог через браузер с когнитивным циклом.

- [ ] FastAPI + WebSocket endpoint с состоянием
- [ ] HTML фронтенд с стримингом и индикатором «думает»
- [ ] Экстрактор фактов (фоновый, не блокирует)
- [ ] Монолог + ответ (стрим) + критик
- [ ] Отображение эмоций в UI (заглушка/заготовка)
- [ ] Тест: 20 диалогов, время ответа < 8 сек

**Блокер:** Phase 0. Phase 1 опционален (можно без голоса).

---

## Phase 3: Память (4–5 дней)
**Цель:** ассистент помнит диалоги и читает книги.

- [ ] bge-m3 эмбеддер (второй Ollama на порту 11435 или CPU)
- [ ] Эпизодическая память: `add_episode` / `recall_episodes`
- [ ] Watcher на `data/library/` (watchdog)
- [ ] Парсер PDF + чанкинг по структуре (оглавление → заголовки → fallback)
- [ ] Retrieval: подмешивание релевантных фрагментов в контекст LLM
- [ ] Тест: кинул книгу → спросил → получил ответ со ссылкой на главу

**Блокер:** Phase 2.

---

## Phase 4: Безопасность и эмоции (3–4 дня)
**Цель:** поведение предсказуемо и эмоционально окрашено.

- [ ] CLIPS: предфильтр входа и финальная проверка выхода
- [ ] CLIPS: жизненный цикл памяти (затухание, access-based promotion)
- [ ] PAD движок: 8 эмоций, decay, влияние на temperature
- [ ] Интеграция PAD в генерацию ответа
- [ ] XP/навыки: начисление по результату действия

**Блокер:** Phase 2 (для безопасности), Phase 3 (для памяти).

---

## Phase 5: SOAR (по факту необходимости, 2+ недели)
**Цель:** обучение через чанкинг, иерархия целей.

- [ ] PySoar / SML интеграция
- [ ] Перенос целей из когнитивного цикла в SOAR
- [ ] Импасс → подцели
- [ ] Чанкинг решённых задач в навыки
- [ ] CLIPS сужается до предфильтра

**Блокер:** Phase 4.

---

## Порядок работы
1. **Phase 0** — обязательно.
2. **Phase 1 и Phase 2** можно вести параллельно (голос не блокирует чат).
3. **Phase 3** после стабильного чата.
4. **Phase 4** после памяти.
5. **Phase 5** — отдельный этап после MVP.
