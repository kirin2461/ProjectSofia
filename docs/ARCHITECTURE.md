# Архитектура Project Sofia

## Поток данных

```
Пользователь (WebSocket)
    ↓
FastAPI Endpoint
    ├── Экстрактор (qwen3:1.7b) → факты
    ├── CLIPS: предфильтр безопасности
    ├── Memory: retrieval эпизодов + библиотека
    ├── Монолог (qwen3:4b, stream=False)
    ├── Ответ (qwen3:4b, stream=True) → WebSocket
    └── Критик (qwen3:4b, stream=False)
        → Обновление PAD, XP, эпизода
```

## Компоненты

| Компонент | Роль | Модель |
|---|---|---|
| Экстрактор | Диалог → структурированные факты | qwen3:1.7b |
| Мозг | Монолог, эмоции, генерация | qwen3:4b |
| Критик | Проверка ответа на противоречия | qwen3:4b |
| Эмбеддер | Векторизация памяти, книг | bge-m3 |
| CLIPS | Правила безопасности и жизненного цикла | — |
| SOAR | Цели, импассы, чанкинг (этап 5) | — |

## Память

- Эпизодическая: события диалога, дневники
- Семантическая (библиотека): книги из `data/library/`
- Процедурная: навыки + чанкинг SOAR

## Эмоции PAD

8 типов, decay, влияние на temperature и тон ответа.
