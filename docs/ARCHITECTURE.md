# Архитектура Project Sofia

## Две среды

```
┌─────────────────────────────────────────────────────────────┐
│  DEV (VDS)                                                  │
│  8 CPU / 8 GB RAM / 75 GB SSD                               │
│  Linux • CPU-only • Без GPU                                 │
│                                                             │
│  Здесь: пишем код, линтинг, юнит-тесты без LLM              │
│  ⚠️ Нет GPU — Ollama на CPU (невероятно медленно)          │
│  ⚠️ Осторожно: всего 8 GB RAM                              │
└────────────────────┬────────────────────────────────────────┘
                     │
                     │ git push / pull
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│  TARGET (Ноутбук)                                           │
│  RTX 5050 8 GB VRAM / 16 GB RAM / Ryzen 7 260AI            │
│  Windows 11 • Ollama локально • GPU CUDA                   │
│                                                             │
│  Здесь: работает ассистент, голос, память, жизнь,          │
│         игры, стриминг, компьютерное зрение                │
└─────────────────────────────────────────────────────────────┘
```

**Ключевой момень:** VDS — это **CPU-only** машина для разработки. Ноутбук — единственное устройство с GPU.

## Что где тестируется

| Тип теста | VDS | Ноутбук |
|---|---|---|

| Захват экрана | ❌ | ✅ |
| Игровое управление | ❌ | ✅ |
| Стриминг | ❌ | ✅ |

## 🎮 Расширенная архитектура: Sofia 2.0

Проект вырос из "ассистента" в "AI-агента с компьютерным зрением, игровым управлением и стримингом".

### Два слоя восприятия-действия

### Компоненты

| Компонент | Роль | Модель/Технология | Где работает |
|---|---|---|---|
| **Экстрактор** | Диалог → факты | qwen3:1.7b | Target GPU |
| **Мозг** | Монолог, эмоции, генерация | qwen3:4b | Target GPU |
| **Критик** | Проверка ответа | qwen3:4b | Target GPU |
| **VLM (Глаза)** | Описание экрана | Qwen3-VL-2B-Heretic | Target GPU (~1.5 GB) |
| **YOLO (Рефлексы)** | Объекты, движение | YOLOv8-nano | Target GPU (~50 MB) |
| **Эмбеддер** | Векторизация памяти | bge-m3 | Target CPU |
| **CLIPS** | Безопасность | — | Target CPU |
| **SOAR** | Цели, чанкинг | — | Target CPU |
| **Захват** | Скриншоты 60 FPS | dxcam / mss | Target CPU |
| **Управление** | Мышь, клавиатура | pyautogui / pydirectinput | Target CPU |
| **Стриминг** | Трансляция | ffmpeg / OBS WebSocket | Target CPU/GPU |

## Ограничения Target (ноутбук)

| Ресурс | Лимит | Как учитывается |
|---|---|---|
| GPU VRAM | 8 ГБ | qwen3:4b (~5.7 GB) + Qwen3-VL-2B (~1.5 GB) + YOLO (~0.1 GB) = ~7.3 GB. XTTS по требованию (~2 GB) — выгружать перед игрой |
| RAM | 16 ГБ | Windows + фон ~5 GB, доступно ~10 GB |
| CPU | 8 ядер (мобильные) | Захват экрана + OpenCV на CPU, LLM/VLM на GPU |
| Диск | SSD | Chroma, книги, логи, записи стримов |

### VRAM-бюджет в режиме "Игра"

```
qwen3:4b (мозг)        ~5.7 GB  ← постоянно
Qwen3-VL-2B (глаза)    ~1.5 GB  ← постоянно
YOLOv8-nano (рефлексы) ~0.1 GB  ← постоянно
────────────────────────────────
Итого:                 ~7.3 GB  ← влезает!

XTTS v2 (~2 GB):       выгружается во время игры
                        (голос отключается или заменяется на beep)
```

### Задержки

| Слой | Задержка | Использование |
|---|---|---|
| Захват экрана (dxcam) | 10–20 мс | 60 FPS |
| YOLO-детекция | 5–15 мс | Рефлексы (прицел, уклонение) |
| VLM-описание | 200–500 мс | Когнитивное восприятие (1–2 раза/сек) |
| LLM-монолог | 1–3 сек | Стратегия (1 раз/5–10 сек) |
| Действие (мышь) | 5–10 мс | Мгновенно |

## Ограничения Dev (VDS)

| Ресурс | Лимит | Как учитывается |
|---|---|---|
| GPU | **НЕТ** | Ollama не запускать, LLM/VLM/YOLO не тестировать |
| RAM | **8 ГБ** | Linux + система ~1-2 GB, доступно ~6 GB |
| CPU | 8 ядер | Можно писать код, линтить |
| Диск | 75 GB SSD | Достаточно для репозитория |

## Dev → Target

1. На VDS пишется код, проверяется синтаксис, юнит-тесты с mock
2. Git push → pull на ноутбук
3. **Все тесты с LLM, VLM, YOLO, захватом экрана — только на ноутбуке**
4. `scripts/benchmark_target.py` — только на ноутбуке

## Голос

XTTS v2 (~2 GB модель) требует GPU. В режиме "Игра" XTTS **выгружается** — или используется мгновенный звуковой сигнал вместо речи для рефлексов.

## Стриминг

- **Захват**: ffmpeg (desktop + микрофон) или OBS Studio с WebSocket API
- **Трансляция**: RTMP на Twitch/YouTube через ffmpeg
- **Оверлей**: SDL/pygame для отображения мыслей агента поверх игры
- **Запись**: локальная запись в `data/streams/`
