# Архитектура Project Sofia

## Две среды

```
┌─────────────────────────────────────────────────────────────┐
│  DEV (VDS)                                                  │
│  8 CPU / 8 GB RAM / 75 GB SSD                               │
│  Linux • CPU-only • Без GPU                                 │
│                                                             │
│  Здесь: пишем код, линтинг, юнит-тесты без LLM              │
│  ⚠️ Нет GPU — Ollama на CPU (невероятно медленно)          │
│  ⚠️ Осторожно: всего 8 GB RAM                              │
└────────────────────┬────────────────────────────────────────┘
                     │
                     │ git push / pull
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│  TARGET (Ноутбук)                                           │
│  RTX 5050 8 GB VRAM / 16 GB RAM / Ryzen 7 260AI            │
│  Windows 11 • Ollama локально • GPU CUDA                   │
│                                                             │
│  Здесь: работает ассистент, голос, память, жизнь            │
│  Здесь: все тесты с LLM, TTS, бенчмарки                     │
└─────────────────────────────────────────────────────────────┘
```

**Ключевой момень:** VDS — это **CPU-only** машина для разработки. Ноутбук — единственное устройство с GPU.

## Что где тестируется

| Тип теста | VDS | Ноутбук |
|---|---|---|
| Синтаксис, линтинг | ✅ | ✅ |
| Юнит-тесты (mock) | ✅ | ✅ |
| Интеграция с Ollama | ❌ (CPU-only, слишком медленно) | ✅ |
| Бенчмарк скорости LLM | ❌ | ✅ |
| XTTS (голос) | ❌ (нет GPU) | ✅ |
| Полный стек | ❌ (8 GB RAM, нет GPU) | ✅ |

## Поток данных (Target)

```
Пользователь (WebSocket / браузер / Telegram)
    ↓
FastAPI Endpoint (localhost:8000)
    ├── Экстрактор (qwen3:1.7b) → структурированные факты
    ├── CLIPS: предфильтр безопасности (мгновенно)
    ├── Memory: retrieval эпизодов + библиотека (bge-m3, CPU)
    ├── Монолог (qwen3:4b, stream=False, think=True)
    ├── Ответ (qwen3:4b, stream=True) → WebSocket
    └── Критик (qwen3:4b, stream=False, think=True)
        → Обновление PAD, XP, запись эпизода
```

## Компоненты

| Компонент | Роль | Модель | Где работает |
|---|---|---|---|
| Экстрактор | Диалог → факты | qwen3:1.7b | Target GPU |
| Мозг | Монолог, эмоции, генерация | qwen3:4b | Target GPU |
| Критик | Проверка ответа | qwen3:4b | Target GPU |
| Эмбеддер | Векторизация памяти, книг | bge-m3 | Target CPU |
| CLIPS | Безопасность, жизненный цикл | — | Target CPU |
| SOAR | Цели, импассы, чанкинг | — | Target CPU (этап 5) |

## Ограничения Target (ноутбук)

| Ресурс | Лимит | Как учитывается |
|---|---|---|
| GPU VRAM | 8 ГБ | qwen3:4b (~5.7 GB) + XTTS по требованию (~2 GB) |
| RAM | 16 ГБ | Windows + фон ~5 GB, доступно ~10 GB для приложения |
| CPU | 8 ядер (мобильные) | Все тяжёлые вычисления на GPU |
| Диск | SSD | Chroma, книги, логи — всё локально |

## Ограничения Dev (VDS)

| Ресурс | Лимит | Как учитывается |
|---|---|---|
| GPU | **НЕТ** | Ollama не запускать, LLM не тестировать |
| RAM | **8 ГБ** | Linux + система ~1-2 GB, доступно ~6 GB |
| CPU | 8 ядер | Можно компилировать, линтить, тестировать логику |
| Диск | 75 GB SSD | Достаточно для репозитория и данных |

## Dev → Target

1. На VDS пишется код, проверяется синтаксис, юнит-тесты с mock
2. Git push → pull на ноутбук
3. **Все тесты с LLM, TTS, скоростью — только на ноутбуке**
4. `scripts/benchmark_target.py` — только на ноутбуке

## Голос

XTTS v2 (~2 GB модель) требует GPU. На VDS тестировать невозможно — только на ноутбуке.
