- **Машина**: VDS (Linux, 8 CPU ядер, 8 GB GPU, **8 GB RAM**, 75 GB SSD)

## ⚠️⚠️⚠️ КРИТИЧЕСКОЕ ПРАВИЛО: Target ≠ Dev

Ты пишешь код на **VDS с 8 GB RAM**, но он **обязан работать на ноутбуке с 16 GB RAM**:

| | Dev (ты здесь) | Target (ноутбук пользователя) |
|---|---|---|
| GPU VRAM | 8 GB | 8 GB (RTX 5050) |
| RAM | **8 GB** | 16 GB |
| CPU | 8 ядер серверных | Ryzen 7 260AI (мобильный) |
| OS | Linux | Windows 11 |
| Диск | 75 GB SSD | SSD |

**75 GB — это диск (SSD), не RAM!** У тебя всего 8 GB оперативной памяти.

## Что ты можешь делать на VDS

1. **Писать код** — все Python-файлы проекта
2. **Тестировать логику по частям** — запускать один компонент за раз
3. **Проверять синтаксис** — `python -m py_compile`
4. **Git** — commit, push в `main`

## Что ты НЕ можешь делать

1. **Запускать весь стек одновременно** — 8 GB RAM не хватит (Ollama + Python + Chroma > 8 GB)
2. **Тестировать на реальном ноутбуке** — у тебя нет доступа к Windows и RTX 5050
3. **Записывать голос** — микрофон VDS не используется
4. **Тестировать XTTS с реальными образцами** — голосовые файлы на ноутбуке
5. **Тестировать GUI/браузер** — VDS без GUI

## Как тестировать на VDS с 8 GB RAM

```bash
# 1. Проверь свободную RAM перед началом
free -h

# 2. Синтаксис и импорты (легко, не требует Ollama)
python -m py_compile core/*.py memory/*.py modules/*.py main.py

# 3. Если нужно протестировать с Ollama — запускай одну модель:
# Останови всё лишнее, проверь VRAM:
nvidia-smi  # или смотри вывод Ollama

# 4. Запускай компоненты изолированно:
python -c "from core.cognitive_cycle import extract_facts; import asyncio; print(asyncio.run(extract_facts('тест')))"

# 5. Следи за RAM в другом терминале:
watch -n 1 free -h
```

## Ограничения, которые ты обязан соблюдать

### VRAM (8 GB — и на VDS, и на ноутбуке)
- qwen3:4b: ~5.7 GB в VRAM
- XTTS v2: ~2 GB (только по требованию, потом выгрузить)
- **Запас**: 0.5 GB
- **Нельзя**: держать 4b + XTTS + другую модель одновременно

### RAM (8 GB на VDS, 16 GB на ноутбуке)
- **На VDS**: Linux + система ~1-2 GB, остаётся 6-7 GB
- Ollama (если модель в VRAM, KV-кэш минимален): ~0.5 GB RAM
- Python + FastAPI: ~0.5 GB
- Chroma: ~0.5-1 GB при 1000 чанков
- **Нельзя на VDS**: запускать Ollama + FastAPI + Chroma + XTTS одновременно
- **На ноутбуке**: Windows ~5 GB, доступно ~10 GB — там можно всё

### Контекст LLM
- Максимум: 32768 токенов (num_ctx)
- Рекомендуется: 8192-16384 для скорости

## Если что-то не работает

1. Проверь `free -h` — не кончилась ли RAM?
2. Проверь `nvidia-smi` — не переполнена ли VRAM?
3. Проверь `scripts/check_ollama.py` — Ollama запущена?
4. Если OOM (out of memory):
   - Убей лишние процессы: `pkill -f python`
   - Перезапусти Ollama: `sudo systemctl restart ollama`
   - Добавь swap: `sudo swapon /swapfile`
5. Если не разберёшься — напиши пользователю лог ошибки

## Финальное правило

> **Код, который требует больше 8 GB RAM для запуска — не попадает в main.**
> **Код, который не укладывается в 16 GB RAM на ноутбуке — не попадает в main.**

Ты пишешь для ноутбука с 16 GB RAM, но тестируешь на VDS с 8 GB RAM. Помни об этом каждую строчку.
