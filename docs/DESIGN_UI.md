# Дизайн интерфейса Софии — «Северное сияние»

## 1. Идея

София — живой собеседник, поэтому в центре экрана не форма, а **она сама**:
светящаяся сфера-«душа», которая дышит, думает и говорит. Её настроение
(эмоциональная модель PAD) окрашивает всё окно — как северное сияние
над ночным небом. Остальное — тихий, аккуратный мессенджер, который не
спорит с ней за внимание.

Три правила:
1. **Эмоция = цвет.** Каждая эмоция задаёт пару цветов; ими окрашены
   сфера, фон-сияние, акценты, рамка ответа. Переход — плавный (1.2 с).
2. **Состояние видно без текста.** Сфера: покой — медленное дыхание;
   думает — вращающееся кольцо; говорит — пульсирует в такт звуку.
3. **Тишина интерфейса.** Стекло (glassmorphism) с малой прозрачностью,
   тонкие линии, крупный читаемый текст, без лишних рамок.

## 2. Палитра

| Роль | Значение |
|---|---|
| Фон | `#070a14` (ночь) + 2 размытых пятна сияния цвета эмоции |
| Стекло | `rgba(255,255,255,.04)`, рамка `rgba(255,255,255,.08)`, blur 18px |
| Текст | `#e8eef9`, вторичный `#8a96b0` (контраст ≥ 4.5:1 на фоне) |
| Пользователь | пузырь-градиент `#2a3f6e → #213157` |
| София | стекло + левая полоса цвета эмоции |

## 3. Раскладка окна (≥ 900 px)

```
┌───────────────┬────────────────────────────────────────────┐
│   ◉ (сфера)   │  София · онлайн                      🔊  ⚙ │  ← шапка
│   СОФИЯ       ├────────────────────────────────────────────┤
│   «радость»   │                                            │
│               │   [пустой экран: приветствие + подсказки]  │
│ Настроение    │                                            │
│ Удовольствие ▬│   ┌──────────────────────┐                 │
│ Возбуждение ▬ │   │ ответ Софии          │ 12:04  ⧉ 🔊     │
│ Доминирован. ▬│   └──────────────────────┘                 │
│               │              ┌──────────────────┐          │
│ Опыт   ★ 120  │              │ сообщение        │          │
│ Модель  gemma │              └──────────────────┘          │
│ Голос   XTTS  │   ● ● ●  София думает                      │
│               ├────────────────────────────────────────────┤
│               │ [ Напишите Софии…            ]   (➤)       │  ← ввод
└───────────────┴────────────────────────────────────────────┘
```

* **Боковая панель 260 px** (сворачивается кнопкой и автоматически
  < 900 px): сфера 140 px, имя, текущая эмоция, три полосы PAD
  (−1…+1, центр — ноль), опыт, модель, состояние голоса.
* **Шапка чата:** статус соединения (точка: зелёная/жёлтая мигающая/
  красная), переключатель голоса, кнопка «очистить экран».
* **Сообщения:** ширина ≤ 720 px, по центру колонки. У Софии — время,
  «копировать», «озвучить ещё раз» (по наведению/фокусу). Простая разметка:
  `**жирный**`, `*курсив*`, `` `код` ``, блоки ```` ``` ````, списки.
* **Пустой экран:** большая сфера-приветствие «Привет! Я София» и 4
  чипа-подсказки («Расскажи о себе», «Как настроение?», «Почитай мне»,
  «Что умеешь?») — клик отправляет.
* **Ввод:** многострочное поле, растёт до 6 строк; Enter — отправить,
  Shift+Enter — новая строка; круглая кнопка отправки цвета эмоции.
  Пока София отвечает, кнопка превращается в индикатор.
* **Соединение потеряно:** тонкая полоса над вводом «Переподключение…»,
  ввод не блокируется визуально резко — только кнопка.

## 4. Сфера (аватар)

SVG/CSS: ядро-градиент (A→B), внешнее свечение `filter: blur`, два
полупрозрачных кольца.

| Состояние | Анимация |
|---|---|
| покой | «дыхание»: масштаб 1 → 1.04, 4 с |
| думает | кольца вращаются (2.4 с), ядро мерцает |
| говорит | масштаб и свечение от громкости звука (WebAudio Analyser) |
| нет связи | серая, без анимации |

`prefers-reduced-motion` — все анимации отключаются, остаётся цвет.

## 5. Приложение (Qt)

* **Тёмная системная рамка** окна (DWM immersive dark mode) — без
  белой полосы заголовка Windows.
* **Заставка** без рамки, скруглённые углы 16 px, тень: та же сфера
  (анимированная), «СОФИЯ», список шагов запуска с отметками
  (○ ожидание → ◌ идёт → ✓ готово → ✕ ошибка):
  1. Подготовка, 2. Оборудование, 3. Модель, 4. llama.cpp,
  5. Загрузка модели в память, 6. Сервер Софии.
  Под списком — тонкий прогресс-бар (с процентами только при скачивании),
  журнал свёрнут под «Подробнее». Окно можно таскать мышью.
* **Ошибка** — шаг красный, текст ошибки, кнопки «Повторить»,
  «Журнал», «Выход».
* **Главное окно:** веб-интерфейс на всю площадь; меню остаётся (Файл /
  Модель / Инструменты) в тёмном стиле; строка состояния убрана —
  модель и железо показывает боковая панель.
* Пока страница грузится — фон окна сразу `#070a14` (без белой вспышки).

## 6. Данные для интерфейса

`GET /state` дополняется: `model` (имя модели), `tts` (голос включён),
`provider`. Панель опрашивает `/state` раз в 5 с и после каждого ответа.
Протокол WebSocket не меняется.

## 7. Доступность

Контраст текста ≥ 4.5:1; видимые фокус-рамки; все кнопки с `aria-label`;
лента сообщений `role="log" aria-live="polite"`; клавиатура: Tab по
элементам, Enter/Shift+Enter, Esc — снять фокус с ввода; уважение
`prefers-reduced-motion`.
